# Nexoda — Telegram-бот онлайн-записи для бизнеса

Бот для записи клиентов на услуги. Клиенты выбирают услугу, мастера и свободное время; владелец управляет расписанием в Telegram. Данные хранятся в SQLite.

---

## Что умеет

**Для клиента (в Telegram):**
- Записаться: услуга → мастер → дата → время → имя → телефон → подтверждение
- «Мои записи» — посмотреть и отменить
- «О нас» — адрес, телефон, часы работы
- Автоматическое напоминание перед визитом

**Для владельца (админка прямо в чате, команда `/admin`):**
- 📋 Записи на сегодня и 🗓 ближайшие записи
- 💈 Услуги: добавить/изменить/скрыть, цена и длительность
- 👤 Мастера: добавить/переименовать/скрыть
- 🕐 Рабочие часы по дням недели + выходные
- ⛔️ Блокировки времени (перерыв, отпуск)
- 📣 Рассылка всем клиентам (акции, новости)
- ⚙️ Настройки: название, адрес, телефон, валюта, за сколько часов напоминать, на сколько дней открыта запись, шаг времени

Мгновенные уведомления владельцу о каждой новой записи и отмене.

## Запуск

### Шаг 1. Получи токен бота
1. Открой Telegram, найди **@BotFather**, отправь `/newbot`.
2. Придумай имя и `@username` бота.
3. BotFather пришлёт **токен** вида `1234567890:AAE...` — скопируй его.

### Шаг 2. Настрой `.env`
Скопируй `.env.example` в `.env` и заполни:
```
BOT_TOKEN=сюда_токен_от_BotFather
ADMIN_IDS=сюда_твой_telegram_id
TIMEZONE=Asia/Tashkent
BUSINESS_NAME=Название салона
```
Узнать свой ID можно через `/id`. Перед тем как давать ссылку на бота клиентам, добавь свой ID в `ADMIN_IDS` и перезапусти процесс. Посетители не получают права владельца автоматически.

### Шаг 3. Запусти
**Windows:** запусти `start.bat`. Скрипт создаст локальное окружение `.venv` и установит зависимости.

**Вручную (Windows):**
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

На Linux и macOS используй `.venv/bin/python` вместо `.venv\Scripts\python.exe`.
После запуска открой `/start`, а затем `/admin` для настройки услуг, мастеров и часов работы.

## Команды
- `/start` — главное меню (для клиентов)
- `/help` — помощь
- `/id` — узнать свой Telegram ID
- `/admin` — панель владельца (только для ID из `ADMIN_IDS`)

## Несколько клиентов (несколько ботов)

Каждый бизнес получает **свой** бот:
1. Скопируй всю папку проекта (например, `NexodaMM-barber1`, `NexodaMM-nails2`).
2. В каждой папке свой `.env` со **своим** `BOT_TOKEN` (новый бот у @BotFather) и `ADMIN_IDS` владельца.
3. Запусти каждую копию: `python main.py`.

База данных у каждого своя (`data/nexoda.db` внутри папки), данные не пересекаются.

## Полезные инструменты

**Готовые пресеты ниш** — быстро заполнить услуги/мастеров/часы под тип бизнеса:
```bash
python apply_preset.py            # список пресетов
python apply_preset.py barbershop # барбершоп (демо)
```
Доступно: `barbershop`, `manicure`, `beauty`, `dental`, `tutor`, `carwash`.

**QR-код на бота** (для печати в салоне и Instagram):
```bash
python make_qr.py имя_бота "Запись онлайн"
```
Файл сохранится в `data/qr_имя_бота.png`.

**Сервер 24/7** — подробная инструкция по выводу на VPS с автозапуском: см. `DEPLOY.md`.

## Частые вопросы

**Бот пишет «не указан токен».** Не заполнен `BOT_TOKEN` в `.env`.

**Админка пишет «только для владельца».** Проверь `ADMIN_IDS`: отправь `/id`, впиши полученное число в `.env` и перезапусти бота.

**Не приходят напоминания.** Бот должен быть запущен постоянно. Проверь `TIMEZONE=Asia/Tashkent` и настройку «Напоминать за … часов» в админке.

Тексты сообщений находятся в `bot/texts.py`, кнопки — в `bot/keyboards.py`.
